## 二、课③ 装备键复活

### 现状诊断(实码钉点)

- a14 仅在有可穿装备时合法(掩码);脚本教师 farm 分支会按
  ([options_env.py:84](python/diablogym/options_env.py:84));塑形价 =
  **+0.5×ΔAC 穿甲时**([env.py](python/diablogym/env.py) v15"教训十三"
  自举塑形:AC 系守恒存量,ΔAC>0 ⟺ 真穿上,不可刷,死亡掉装负 Δ 不罚)。
- **灭绝事实**:v28 五万次调用 a14 = 0 次(FORENSICS-神之一手 #3)。
- **机理假说 H③(单价错配)**:+0.5×ΔAC 是一次性小额(一件甲 ΔAC≈2-5
  → +1~2.5,≈半只怪),而甲的真实价值是**深层存活率的复利**;浅层
  (0-2 层)伤害可由药/反射兜底,学习者在其经验分布内感受不到甲的边际
  价值。对照组:a13 囤药为什么活了——它喂给 0.5 反射,回报即时可感。

### 方案(按刀口从小到大)

- **③A 诊断先行案(零环境改动)**:反事实探针——脚本工人(会穿甲)
  vs 被剥夺 a14 的同款脚本,7000 池逐种子配对,按深度分层测"甲的因果
  价值曲线 V_AC(depth)" + a14 机会频次统计。若 V_AC 在 3 层+显著为正而
  浅层 ≈0 → H③ 证实。**零批文,知会即可排队。**
- **③C BC 正样本注入(训练侧)**:demos 里 a14 样本天然存在(脚本按),
  只是 <300 对不入门槛类;类加权/过采样让 BC 教师把 14 学实,PPO 期由
  β 皮筋护住。**零环境改动、零批文。**
- **③B′ 训练侧塑形(小批文)**:仅在训练包装器给 a14 即时加成,**评测
  账本一字不动**——规避再定锚。代价:新增一条训练/评测口径错配(课⑤
  正在消的病),须显式登记。
- **③B 评测价格表复审(大批文,原则上不推荐)**:改 env.py 单价即改
  评测回报口径 → **协议升版 → R2 之锚全体再定**。成本巨大,仅备案。

**推荐次序:③A 诊断 → 证实则 ③C 先试(最便宜)→ 不动再议 ③B′;
③B 封存备案。**
