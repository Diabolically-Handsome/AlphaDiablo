## 常设条款:完美证言(2026-07-12 总设计师核准,N=3 亲定)

**任一组件或结论,连续 3 次审查零发现 → 强制触发异源 Agent 审计。**
法理(总设计师原话):"当一件事情无论从各个方面都找不到他的问题,
那这件事情本身可能就是问题。"同源探测器(自审、自建面板)与被审对象
共享盲区,零发现是弱证据;凡完美者,必受质询。执行细则:① 计数以
"审查事件"为单位(面板过审、验收、复跑各计一次);② 触发后 hands-off
——审计 Agent 工作期间本席不碰仓库;③ 收工走验收面板(通读 diff →
复跑回归 → 语义重放 → 分类);④ commit/push 仍由总设计师批。
