### L1a release width limb (currently ≥18/32)

- **Derivation principle (frozen)**: under the zero-improvement null (per-seed sign flips; no measurement noise under the deterministic protocol), the single-limb false-crowning rate of the width limb α_width := 0.05; k* := min{k : P(X≥k | n=32, p=.5) ≤ 0.05}, exact binomial.
- **Registered α semantics (rev2, statistics seat M-1)**: the semantic unit of α = **per-candidate, single-limb, marginal**. The release line is a conjunctive gate, and the case history records that "the winner is a max-of-2 order statistic" -- joint and selection effects are not controlled by this constant but are controlled by mandatory listing in the OC table: (i) a joint-α column (rate at which width ∧ mean difference both pass under the same permutation null); (ii) a max-of-2 correction column (effective α when the winner of two arms is taken); (iii) a cross-case draw family-error note. **Discretionary reason (registered)**: each family has N=1 healthy vector, so registering a joint calibration target would overfit to 2 vectors; hence the "marginal calibration + joint listing" form.
- **Tie counting (rev2, statistics seat m-2)**: Δ=0 does not count as a win; in the permutation, zero values always contribute 0 (invariant under flipping), counted as is.
