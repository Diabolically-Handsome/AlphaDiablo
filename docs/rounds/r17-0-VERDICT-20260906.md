## 2. Two findings (formally filed)

**Finding 1: in deployment the manager hardly matters.** The same R16 arm (7e31dc54) under four scripted
managers, readiness-v3 / readiness-v3-strict / const-FARM / const-DIVE: survival 17/17/17/16, L2 reached
28/28/29/30, while the forced-descent share is 0.536 / 0.536 / 1.000 / 0.000 respectively. v3 and -strict
are bit-identical, which proves the `cleared` branch never triggers in deployment (L1 is never cleared
within 6000 steps). Conclusion: R17's lever must be the affordances of the environment (a resource
channel), not the manager rules. This is a measurement, not an inference.

**Finding 2: only half of it is a ruler artefact.** After switching training to the v0.2 ruler, escrow
vested is still 0, because the descent rows are clvl 2 / AC 7 (starting armour) / ratio_v2 0.778, so "not
ready" is the correct call; R16's "none of 244 descents met the bar" is not a ruler artefact on the training
side. Only the part where 4 of the 10 L2 arrivals in deployment had AC≥9 is an artefact. AC 9 still needs a
dropped armour piece, and gold is still 100.

  ready": **hands (affordances) and money (economy)**.
