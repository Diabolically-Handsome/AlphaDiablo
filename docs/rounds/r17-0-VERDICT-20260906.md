const-FARM / const-DIVE 四种脚本经理下:存活 17/17/17/16,L2 到达 28/28/29/30,而强制下楼份额分别为
0.536 / 0.536 / 1.000 / 0.000。v3 与 -strict 逐位相同,证明 `cleared` 分支在部署中从不触发(6000 拍内
L1 清不空)。结论:R17 的杠杆必须在环境可供性(资源通道),不在经理规则。这是实测,不是推理。
