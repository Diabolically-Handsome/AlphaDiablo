## 2. Mechanism (option A, revised after the theory review)
- φ(s) = unit × (deepest level this episode − 1), unit=8.0, **a monotone potential** (theory review
  ruling: once live DIVE windows are exempt from the cell-stepping protection, upward transitions exist,
  and a current-level potential would heavily penalise going up / retreating; a monotone potential does
  not deduct for going up, is immune to cycles, and pays only for new progress);
- F = φ(s′) − φ(s) per live transition, added to the worker's policy_reward;
- a true terminal (death / completion / no-progress death) refunds −φ(s_T), enforcing φ(absorbing)=0
  ⇒ **ΣF ≡ 0 over any complete trajectory** (the constitutional core: it changes when payment happens,
  not the net payment, so it is not a descent bonus in disguise);
- truncation (3000 steps) gets no refund: the theory review proved that the critic learns V−φ and
  bootstrapping hedges it exactly; "no refund + bootstrap" is the only self-consistent combination (refund
  + bootstrap = a double deduction that teaches refusing to dive);
- it enters only the worker's policy_reward: the manager's ledger, the wage identity R≡W+bonus and exam
  scoring are untouched; under the v1 economy it refuses to activate, fail-closed (the deepest-level
  tracker depends on v2+).

- Mechanism = pre-inject the long-term value of descending into the critic (the Wiewiora 2003
  equivalence); it changes which local optimum is reached, not the global optimum;
